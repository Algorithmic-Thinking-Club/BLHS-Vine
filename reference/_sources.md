## What the architecture actually is (load-bearing for the world map)
From Erickson McGovern (EMA), the real architect:
- 49-acre campus, ~207,539 sq ft, opened Sept 2005; 2011 addition; PAC added later.
- Organized as **small learning communities radiating from a two-story commons** — each community = ~5 classrooms around a central project area + shared faculty office.
- The **commons** doubles as a performance venue and holds **"storefronts"**: a student-run **bank (BECU)**, **career center**, **ASB/student-body office**, and a **food court for culinary arts**.
- PAC exterior = **insulated glass storefronts + metal panels**; PAC interior = soft monochromatic palette + wood accents, a "wave" motif.
- → This radial commons + learning-community plan is a near-perfect real-world map for the district→building model. The commons = the hub players spawn into; learning communities + PAC + gym + culinary = districts.
