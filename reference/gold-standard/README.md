# Gold standard — the visual bar for the BLHS Adventure Game

The world must reach the quality of these references (Ash's gold standard, set 2026-06-24):

1. **TavernWorld — town square at night.** Dense isometric medieval town: large detailed
   buildings with lit windows, cobblestone plaza, warm lantern light, atmospheric fog, depth.
   The lighting and density are the bar.
2. **TavernWorld — underground tavern interior.** Painterly iso room: glowing mushrooms, tree
   roots, lanterns, books, a water pool with a runic circle. Cohesive, atmospheric, rich.
3. **Isometric office / study room.** Clean detailed iso room: desks, computers, bookshelves,
   plants, warm light, characters with speech bubbles. Clean + professional.
4. **Star-Office-UI (ringhyacinth).** Cozy Stardew-style rooms: detailed furniture, plants, warm
   tilework, banners. The cozy-but-crisp tile detail is the bar.

Plus **Prodigy** (the math edu-RPG): a vast, beautiful, explorable pixel-RPG world with real
terrain depth (hills, stairs, water, layers). Our world is that, slightly more RPG-pixelated.

These four images were shared in chat; they live in Ash's references. Re-paste them here as
`tavern-town.jpg`, `tavern-interior.jpg`, `iso-office.jpg`, `star-office-ui.jpg` when convenient.

vectors). The world's layout must follow it: running track + football field NW, building complex
center, large parking lots, baseball/softball diamonds SE, dense PNW evergreen forest all around.
