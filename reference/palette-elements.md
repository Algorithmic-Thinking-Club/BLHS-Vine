# BLHS true per-element palette (for generation prompts + tile authoring)

> Sampled from the real Erickson McGovern campus photos. Use these to keep generated art accurate.
> See `palette-elements.html` for swatches.

## The one-line truth
BLHS is a modern PNW school: **warm light greige metal-panel siding (the body)** + **red-brick base
and entry columns (accent)** + **dark gray-brown low-slope roofs** + **light concrete plazas** + **lush
green landscaping with dark bark mulch** against an **evergreen backdrop**. Teal/black = mascot + UI only.

## Architecture
- siding body `#c6bfae` (warm greige metal panel) / shadow `#a59e8c` — this is MOST of the wall area
- brick accent `#9c5640` (base + entry columns) / dark `#7c4332` / mortar `#b9a892`
- roof + fascia `#554a40` (dark gray-brown, low-slope + shed angles)
- window frame `#37352f` (dark bronze) / glass `#a9bcc4` (pale sky reflection)

## Ground
- concrete plaza/sidewalk/steps `#bdb7ab` / control-joint `#8f897d`
- asphalt (parking, drop-off) `#4d4a47`
- bark mulch / tanbark `#43301f` (dark brown) / light `#5a4330`

## Landscape
- grass `#52733c` / highlight `#6d8f48`
- shrubs `#3f592f`–`#6d8a4c`; red-twig dogwood accent `#b23528`
- conifer backdrop `#2c3f26` (PNW evergreens ring the site)

## Sky
- clear `#4a86c6` / pale `#9fc0dd` / overcast `#b4babe` (Pacific NW is often overcast)

## Prompt phrasing (reuse verbatim)
"modern Pacific-Northwest high school, warm light greige metal-panel siding with red-brick base and
columns, dark gray-brown low-slope roofs, concrete plaza and steps, lush green lawn with dark bark-mulch
planters, evergreen trees behind, overcast soft light" — NOT a solid red-brick building, NOT teal walls.
